# 字幕 · 口播 · 背景音乐 · 属性设置 —— 实施清单

> 目标：在现有 OpenReel 编辑器上补齐「Whisper AI 字幕 → 独立字幕轨 → 字幕调整 →
> 口播录音 → 背景音乐 → 音视频/字幕属性」的完整链路，并统一为 Apple 设计语言。
>
> 状态标记：`[x]` 已完成并验证 / `[~]` 进行中 / `[ ]` 待办

## A. 独立字幕轨（核心）

- [x] A1. 字幕轨使用可识别的 `role: "captions"`，时间线轨道头显示「字幕」徽标与字幕图标，不再和视频轨 V1 混在一起。
- [x] A2. 新建/追加字幕时自动复用已有字幕轨；没有时自动创建「字幕」轨，并置于视频轨上方（保证导出可见）。
- [x] A3. 字幕只能落在字幕轨：字幕批次编辑、SRT 导入、Whisper 生成统一走同一条轨道；不写入视频轨。
- [x] A4. 字幕轨支持锁定/隐藏/重命名/拖拽排序，并保留“置于顶层”修复入口。

## B. Whisper AI 字幕

- [x] B1. 选中片段 → Whisper 本地转写 → 生成单行字幕文本片段。
- [x] B2. 整条时间线一键转写：自动跳过已有 AI 字幕的片段，按片段速度/入点映射时间。
- [x] B3. 显示模型下载进度、转写进度、后端（GPU/CPU）、错误提示。
- [x] B4. 字幕语言、模型质量、每行字数可调。

## C. 字幕调整

- [x] C1. 独立的「字幕」工作台标签页（左侧资源区），聚合 AI 生成、逐条编辑、查找替换、单行拆分。
- [x] C2. 时间线上点选字幕片段 → 右侧属性面板可改文本、字体、字号、颜色、背景、描边、阴影。
- [x] C3. 字幕快捷属性：位置（顶部/居中/底部）、背景样式、字号预设、一键应用到全部字幕。
- [x] C4. SRT / VTT 导入导出（导出为 .srt 下载）。
- [x] C5. 字幕时间调整：拖动/裁剪字幕片段，或通过属性面板修改起止时间。

## D. 口播 / 配音

- [x] D1. 左侧「AI 工具」新增「口播配音」入口，未选中片段也能直接录音。
- [x] D2. 录音自动放入独立「配音」轨（`role: "dialogue"`），复用已有配音轨，不新建一堆轨道。
- [x] D3. 3 秒倒计时、录音计时、保存状态、权限错误提示。
- [x] D4. 录制片段与播放头对齐，可在时间线继续裁剪、移动、调音量。

## E. 背景音乐

- [x] E1. 音乐库添加曲目时自动进入「背景音乐」轨（`role: "music"`），复用轨道并在播放头处插入。
- [x] E2. 默认音量与淡入/淡出，避免压住口播。
- [x] E3. 支持上传本地背景音乐到同一轨道。
- [x] E4. 属性面板提供背景音乐音量、淡入淡出、自动闪避（Ducking）。

## F. 属性设置

- [x] F1. 视频属性：变换、裁剪、颜色、效果、速度、动画（已有，检查入口）。
- [x] F2. 音频属性：音量、淡入淡出、降噪、EQ、压缩、闪避（已有，检查入口）。
- [x] F3. 字幕属性：文本、字体、字号、颜色、背景、位置、动画（补齐快捷分组）。
- [x] F4. 轨道属性：字幕/配音/背景音乐的角色徽标与轨道级操作。

## G. Apple 设计语言

- [x] G1. 统一浅色 Apple 主题为默认：`#F5F5F7` 背景、白色卡片、`#0071E3` Action Blue、发丝线边框。
- [x] G2. 去除密集的 9–10px 小字，面板正文 ≥ 12px，标题 13–15px，字重克制。
- [x] G3. 卡片圆角 10–14px，阴影极轻；按钮使用胶囊主按钮 + 次级浅灰按钮。
- [x] G4. AI 工具入口去掉彩色渐变，统一为 Apple 蓝 + 中性灰图标。
- [x] G5. 字幕/口播/音乐/属性面板在浅色与深色主题下都可读。

## H. 验证

- [x] H1. `pnpm --filter @openreel/web typecheck`
- [x] H2. 字幕相关单测 + 关键面板测试通过。
